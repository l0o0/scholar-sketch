# 本地保存保护与恢复

Markdown 标签页、独立窗口、侧边编辑器及 API 更新使用同一个保存入口；Canvas
使用相同的文件冲突检查。编辑器保留加载时的原文，每次写入前比较磁盘正文。
文件内容已变化时停止覆盖，把当前草稿保存为本地冲突版本。即使文件修改时间和大小
不变，也能识别内容变化。同一路径的插件写入串行执行，历史落盘后再次检查原文。
外部应用不参与本插件的写入队列，因此这不是跨进程文件锁；请避免同时编辑同一文件。

## 本地历史

- Markdown 的“更多 → 本地历史”，或 Markdown / Canvas 附件右键的“本地历史”。
- 可选取版本、预览原文，并另存恢复副本。Canvas 预览为 JSON 卡片数据。
- 恢复副本必须使用新文件名，不覆盖当前文件；之后可以作为附件重新导入 Zotero。
- 每个附件分别保留最近 50 个保存前版本及最近 50 个冲突草稿。重复的最新内容不会再次备份。
- 存放于 Zotero 数据目录的 `scholar-canvas/history/<libraryID>/<attachmentKey>/`。
  重命名附件不改变历史身份。历史只存本机，不参与 Zotero 同步。
- 历史包含 Markdown 正文或 Canvas 文件内容（包括已嵌入 Canvas 的文件），不复制单独引用的图片、PDF 等资源；恢复含外部资源的文档
  时仍需要原资源。这不是完整的附件备份。恢复副本位于其他目录时还需要迁移资源或调整路径。
- 备份写入失败会中止文件覆盖；原文件保留。请处理磁盘或权限错误后重试。

冲突时可先从历史另存草稿，重新打开附件读取外部版本，再对照合并。
`force` 保存只表示立即保存，不绕过外部修改检查。

## Markdown 目录导出

本地图片支持 Markdown 内联及引用式图片、HTML 图片和 Wiki 图片。除原有 `assets/`
图片外，同级、子目录和上级相对路径的图片也会复制；路径按各笔记隔离，同名或仅大小写
不同的图片不会互相覆盖。输出使用目录内路径，不包含 `..`。

支持 PNG、JPEG、GIF、WebP、SVG、AVIF、BMP、TIFF 扩展名；这只是图片资源搬运，
不承诺编辑器支持预览全部格式。绝对路径、`file:` URL 及非图片文档嵌入不会复制，
会在 `REPORT.md` 中报告。远程图片仍保留原 URL，离线导出前可先使用“下载外链图片到本地”。

## 旧版同步设置迁移

旧版将教程内容指纹和白板模板写入 Zotero 不支持的同步设置，可能造成
`Invalid setting 'bamboo.tutorialBaseline.…'` 或
`Invalid setting 'bamboo.noteTemplates.v1'` 并中断该文库上传。
插件启动时只处理这两个明确的键名范围，不修改其他插件或 Zotero 原生设置。

教程内容指纹是可丢弃的辅助数据，直接清理，不另存历史。个人文库的旧自定义模板
迁入本地 `extensions.zotero.bamboo.noteTemplates` 配置；同 ID 的不同模板保留为
独立副本。保存后读取磁盘配置核对该键，成功后才移除旧模板设置。写入或核对失败时
保留原模板、提示错误，下次启动重试，不阻断 Markdown 与白板使用。

清理旧设置时不生成远端删除请求，同时移除对应的待同步删除记录，不影响其他设置
或条目。每次启动都检查旧键，以处理旧版再次写入的记录。相关电脑都应升级；已开始
的同步可能仍使用迁移前的快照，需要在迁移成功后重试。此修复只处理这些非法设置，
不代表网络、凭据或其他插件导致的同步错误也已解决。
