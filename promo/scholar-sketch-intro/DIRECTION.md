## 2. 产品气质

- **做什么、给谁用：** Zotero 9 / 10 / 11 桌面插件，把 Markdown 笔记和研究白板放进 Zotero（`README.md`）。用户是在 Zotero 里管文献的研究者，长时间读和写，中英文混用（`PRODUCT.md` Users）。
- **用起来的感觉：** “Quiet, precise, and native”，像一张可靠的研究书桌；要分清“原文”和“自己的想法”（`PRODUCT.md` Brand Personality、Design Principles 1）。
- **反例：** 仪表盘卡片网格、装饰渐变、玻璃、大阴影、营销式构图（`PRODUCT.md` Anti-references）。
- **设计语言（来源见 `evidence/style-audit.md`）：**
  - 色板：产品 UI 纸白 `#fbfbfc` / 白 `#ffffff` / 墨 `#111827` / 弱字 `#6b7280` / 描边 `#e5e7eb`，蓝 `#2563eb` 只用于链接、焦点、选中（`src/ui/theme.ts`）。品牌墨 `#1a2527`、鼠尾草绿 `#718b7a`（标志实测）。
  - 卡片：问题暖黄虚线、观点浅绿 2px、证据浅蓝方角、总结淡紫、笔记白（`packages/whiteboard/src/model/academic.ts`）。连线：支持 `#2f855a`、反驳 `#c2413a` 虚线、相关 `#64748b`。
  - 字体：系统黑体栈（PingFang SC / 微软雅黑），没有品牌字体。圆角 8 / 12，1px 描边，阴影几乎看不见。
  - 明暗：完整的浅色和深色主题，默认“跟随系统”（`addon/prefs.js:4`，`src/modules/markdown/editor.ts:599`，`src/modules/whiteboard/tab.ts:128`）。
- **母题（能直接变成画面的产品元素）：**
  - 标志：一张墨线画的纸页，右下角折起，折角是鼠尾草绿（`docs/icons/scholar-sketch-logo.png`）。
  - 两种附件图标：纸页 + 流程图（`.canvas`），纸页 + M（`.md`）（`addon/content/icons/attachment-*.svg`），也是工具栏菜单里“新建白板… / 新建 Markdown 笔记…”的图标。
  - 白板画布本身：16px 点阵纸面、卡片、贝塞尔连线、批注色点。
  - 来源不丢：同一篇论文可以变成文献卡、引文卡、笔记里的链接、它名下的附件（`PRODUCT.md` Product Purpose：“without losing provenance”）。

## 3. 三个方向（沿不同的轴拉开）

三位导演各自写了完整提案（`A`/`B`/`C`，原文存在制作记录里），再由三位独立评审按“品牌与诚实”“观众理解与文案”“手艺与可行性”打分。

| 方向 | 底色与光 | 字体声音 | 母题来源 | 镜头语言 | 节奏 | 音乐 | 评审分（品牌 / 观众 / 手艺） |
|---|---|---|---|---|---|---|---|
| A 书桌一镜到底 | 全片纸白点阵 | 600 安静字重 | 界面 + 书桌 | 一镜到底，只平移推拉 | 安静叙事 80 BPM | 毡音钢琴 + 弓弦，无打击乐 | 7.5 / 7 / 5.5 |
| B 折角翻页 | 明暗交替 7 次 | 700 粗重编辑感 | 标志几何 | 平面排版 + 3 倍微距 | 发布会式 100 BPM | 拨奏脉冲 + 纸张打击 | 5 / 7.5 / 7 |
| C 任务实录 | 全片纸白 | 录屏标注 | 用户任务 | 录屏质感 + 光标推近 | 轻快 120 BPM | 刷子鼓 + 电钢琴 | 7 / 6 / 6.5 |

评审要点：
- A 最符合“安静、精确、原生”，但全片无切、无明暗变化，观众抓不到章节；一镜到底的世界坐标工程量最大；“卡片标题叠化成笔记链接”会让人以为有自动转换功能。
- B 章节清楚、版式有数字，但折角和变形太多、改了标志形状和颜色、字太重，偏营销；两个演示题目不统一。
- C 的“同一句话跨界面接力”会被误读成白板和笔记自动同步；录屏感把重建的 Zotero 外壳和真实组件混成一段“会话”。
- 三位评审都要求：全片只用一个演示题目；所有提示条用产品自己的 × 关掉；未验证的交互先写好退路。

## 4. 选择与理由

**选 A 的气质，加 B 的章节路标，去掉三者的诚实风险。** 方向名“页边批注”：产品窗口是“那页纸”，片子的话写在页边，像研究者读书时写的批注。

- **为什么：** 这个产品的承诺是安静和不丢来源（`PRODUCT.md`）。A 的毡音钢琴、平光纸面、中等字重最贴近；观众需要知道“它有哪几块”，所以用产品自己的两个附件图标做章节页眉（B）；明暗变化只来自产品真实的“外观跟随系统”，只出现一次。
- **改掉的地方：** 不做一镜到底的世界坐标（分章节，章内连续，章间翻页）；外层纸色比产品画布暗一档、不带点阵，让观众分清片子包装和真实界面；不做“卡片变成链接”的叠化，也不做“一句话跨界面接力”。

### 本片专属手法（4 个）

1. **一笔画出的折角纸页 → 开场与章节翻页。**
   - 因为：标志是一张墨线画成、右下角折起的纸页，折角是鼠尾草绿（`docs/icons/scholar-sketch-logo.png`；同一几何也在 `addon/content/icons/scholar-sketch-toolbar.svg`）。
   - 所以：开场用沿纸页轮廓走的描边遮罩把**原图标志**“一笔画出来”，折角最后翻进来（不改形、不换色，落定就是原 PNG）。章节之间用同一个折角翻页：一条 45° 折线从右下角扫向左上角，翻起的是鼠尾草绿纸背，下面露出下一章。全片只翻 2 次（白板 → 笔记；深色 → 文件）。
   - 实现：遮罩是 SVG `stroke-dashoffset`，挂在 GSAP 主时间轴；翻页是 `clip-path: polygon()` 的纯函数 + 一块绿色折片三角形，由 `onRender` 按时间计算。
2. **附件图标做路标。**
   - 因为：插件的两种文件有自己的图标，`attachment-canvas.svg`（纸页 + 流程图）和 `attachment-markdown.svg`（纸页 + M），它们也是工具栏菜单“新建白板…”“新建 Markdown 笔记…”的图标。
   - 所以：同一个图标从工具栏菜单（#2）走到章节页眉（#3、#8），最后是文献名下的附件行（#12）。观众一路看到的是同两样东西。
   - 实现：直接用仓库 SVG（`public/addon-icons/`），位置变化挂在 GSAP 主时间轴。
3. **跟着同一篇论文接续。**
   - 因为：产品让来源一路跟着走：拖进白板是文献卡（`nodes/academic.tsx` LiteratureNode），它的 PDF 高亮变成带同色圆点和页码的引文卡（`AnnotationBrowser.tsx` → QuoteNode），笔记里 `[[` 能搜到同一篇论文（`document-links.ts searchDocumentLinks`），笔记和白板又是它名下的附件。
   - 所以：全片只有一篇主角论文《城市公园冷岛效应的尺度阈值》（虚构）。关键处做“对位接续”：#4 点“添加所选批注”的那一帧，xyflow 视口跳到让第一张新引文卡的黄色圆点正好落在弹窗里那颗黄点的屏幕位置，然后再缓移构图；#9 `[[` 弹层里被选中的就是这篇论文；#12 两个附件行挂在它名下。
   - 实现：builder 预跑真实交互时测出屏幕位置，再反算视口；跳位放在同一个 seek 步骤里，前后跳帧一致。
4. **字写在页边，只有产品自己会打字。**
   - 因为：产品要分清“原文”和“自己的想法”，气质是安静的研究书桌（`PRODUCT.md`）；产品窗口里的变化都来自真实操作。
   - 所以：片子的标题和说明写在产品窗口旁边的页边栏，像页边批注；外层纸色 `#f2f2ee` 比产品画布 `#fbfbfc` 暗一档、不带点阵，产品窗口有 1px 边框，观众分得清哪是片子、哪是产品。片子的字只淡入上移，不做打字机效果；画面里出现的打字都是产品编辑器里的真实输入。

### 与本工作区既往影片的区别

这是本工作区第一支片子。与 skill 案例（CodePilot）相比：不用星空 / 流线开场、银白光弧、粒子汇聚成点阵、字符场、环绕、发光地平线、Ask/Switch/Extend 式章节大字、透视倾斜面板；配乐不用电影感电子乐和低频冲击。

## 5. 画面规范

### 5.1 画幅、底色、安全区

- 1920×1080，30 fps，58.5 秒（1755 帧）。
- 外层纸色 `#f2f2ee`（不带点阵）；深色镜头外层用品牌墨 `#1a2527`。
- 安全区：左右 96px，上 56px，底部 140px（片子的字不进 y > 940）。产品窗口可以延伸到 y 1024。

### 5.2 版式

| 版式 | 页边栏（片子的字） | 产品窗口 | 用在 |
|---|---|---|---|
| L 左页边 | x 96–560（页眉 y 96，版本标签 y 332，标题 y 392，说明 y 560） | 白板窗口 x 608–1856，y 56–1024（1248×968） | 第一章 #3–#7 |
| T 顶部文字条 | y 56–236：标题在左（x 96–916），说明在右（x 976–1824） | 笔记窗口 x 64–1856，y 250–1024（1792×774） | 第二章 #8–#10 |
| D 两页叠放 | 顶部文字条同 T | 笔记窗口缩到 0.62 放在左后方（x 64，y 252），白板窗口缩到 0.72 放在右前方（x 956，y 300） | #11 深色 |
| 字卡 | 居中构图 | 无 | #1、#2、#12、#13 |

- 为什么第二章换成顶部文字条：Markdown 标签页要同时放下目录、正文和“引用此笔记”，在 1.6 倍下至少需要约 1100 个产品像素宽；页边栏版式只给得出 780。换版式也让两章一眼能分开。
- 窗口的基础尺寸固定（白板 1248×968，笔记 1792×774），版式切换只移动、缩放整个窗口，产品内部不会重新排版。
- 产品窗口：圆角 16，1px `#dcdcd5` 边，阴影 `0 1px 2px rgba(16,24,40,.06), 0 10px 28px rgba(16,24,40,.07)`（不超过产品菜单阴影）。深色时边框 `#3d4452`。
- 页眉（章节路标）：页边栏顶部 y 96，真实附件图标 44px + 章名 26px / 500 `#596066`，下面一条 48×2px 鼠尾草绿短线。

### 5.3 字号阶梯（成片像素）

| 层级 | 字体 | 字号 / 字重 / 行高 | 颜色 | 规则 |
|---|---|---|---|---|
| 字卡主句 | Film Sans SC（Noto Sans SC） | 52px / 500 / 1.4 | `#1a2527` | 每行 ≤ 18 字 |
| 主标题 | Film Sans SC | 58px / 600 / 1.22，字距 0.01em | `#1a2527` | 页边栏宽 464px，每行 ≤ 8 字，手动断行 |
| 说明 | Film Sans SC | 32px / 400 / 1.6 | `#454d50` | 每行 ≤ 14 字，≤ 4 行，标点不单独掉行 |
| 页眉章名 | Film Sans SC | 26px / 500 | `#596066` | |
| 版本标签 | Inter 500 + Film Sans SC 500 | 22px | `#596066` | 1px `#c9cfcc` 圆角胶囊，内边距 4×14 |
| “示意”小字 | Film Sans SC | 18px / 400 | `#9aa1a0` | 只标在重建画面上 |
| 片尾标语 | Film Sans SC | 34px / 500，字距 0.5em | `#596066` | |
| 片尾平台行 | Film Sans SC + Inter | 24px / 400 | `#6b7280` | |

- 全中文：用户选择“横版 45–60 秒，全中文”，不放英文标题层（`plan.typography.exceptionReason`）。产品名 Scholar Sketch、Zotero、Markdown、`.md`、`[[` 这些专有名词保留原文，用 Inter 单独的 span。

### 5.4 产品上镜倍数（正文 ≥ 22px）

| 界面 | 倍数 | 成片正文 |
|---|---|---|
| 白板 `WhiteboardApp` | S = 1.85，xyflow 视口 1.00–1.30 | 卡片正文 22.2–28.9px；只有建立全局的一拍（≤ 1.5 秒）低于 1.0 |
| 批注弹窗（#4） | S 1.85 × 外层 0.92 = 1.70 | 弹窗正文 13px → 22.1px；弹窗 678 → 1153px 宽，放得进 1248px 窗口 |

| “引用此笔记”面板 | 1.6 × 外层 1.3 = 2.08 | 引用正文 25px |
| 标志 PNG | ≤ 1×（去掉英文标语的版本 `public/brand/logo-lockup.png`） | 不放大 |

### 5.5 明暗

全片亮色，只有 #11 一次深色：系统切到深色，产品自己的深色主题。亮 → 暗在镜头内由产品真实切换完成；暗 → 亮用折角翻页（硬边），不做交叉淡化。

### 5.6 动效语法

- **片子的字：** 标题淡入 + 上移 12px，0.45 秒 `power2.out`；说明晚 0.25 秒，同样方式；版本标签 1px 边框先描出 0.3 秒再出字；退场淡出 0.3 秒 `power1.in`，在转场前结束。
- **产品窗口：** 版式切换时整体平移 / 缩放 0.8–1.2 秒 `power2.inOut`。
- **白板镜头：** xyflow `setViewport` 推拉 0.6–1.2 秒 `power2.inOut`；有卡片被选中时不移动镜头（样式条会跳）。
- **光标：** 墨色箭头 30px（白描边），移动 0.5–0.8 秒 `power2.inOut`，点击落在拍点上；格式刷时换成产品自己的刷子光标。
- **界面变化：** 只来自真实点击、勾选、拖动、输入。不给真实界面加假的入场动画。
- **折角翻页：** 0.7 秒 `power2.inOut`，全片 2 次。
- **缓动族：** 只用 power1–3、sine。
- **不用：** 回弹、弹性、模糊入场、打字机标题、闪白、黑场、发光、渐变、玻璃、外层点阵、3D 倾斜、粒子、星空、光弧、字符场、章节大字、明暗交叉淡化、镜头抖动。

## 7. 配乐与声音

- **来源：** 代码原创合成（`assets/audio/score.py`，固定随机种子，保留源码），只借 skill 示例的合成手法。
- **速度与调性：** 90 BPM，4/4，F 大调；一小节 2.667 秒。
- **配器（从“安静、精确、书桌”推出）：** 毡音钢琴（主角）；弓弦质感的长音铺底（低通，起音慢）；正弦低音；第一章和第二章中段加极轻的“纸张”节奏（滤波噪声短音，2、4 拍），读字时退后。不用鼓组、马林巴、电子脉冲、上升音、低频冲击、侧链。
- **段落按镜头边界：** 开场单音（#1）→ 开放五度、轻铺底（#2）→ A 段“研究白板”（#3–#7，分解和弦 + 纸张节奏，#5 起“思路”上行动机，25.83 停一拍给格式刷）→ 翻页处只留铺底一拍 → B 段“Markdown 笔记”（#8–#10，均匀八分琶音像写字的节奏）→ #11 深色：低音区和弦、织体变暗 → #12 只留钢琴长音 → #13 主和弦 Fadd9 落下，长尾音收束。
- **音效：** 独立音轨。点击、勾选、弹出、打字用 skill 内置 WAV；轻落声、纸声、刷声用 `scripts/make_sfx.py` 的手法另外合成（固定种子）。镜头移动不加声音，不用 whoosh 和冲击音。落点用 `sfx_landmarks.py` 实测。
- **混音：** 音效出现时音乐让位（`audio.ducking`），整片约 −16 LUFS。
